# Attribution

Where the models came from, and under what licence.

Everything here was generated by a script until Phase 3.5. From here the game
uses real, artist-made assets, which means the provenance of each one has to be
written down — CC0 asserts no attribution requirement, but "we believe this was
CC0" is not a record, and a licence nobody wrote down is a licence nobody can
check later.

## The rule

**Verify the licence at download time, per model, and record it here.** Do not
assume a pack is CC0 because the site is known for CC0 packs, and do not assume
every model inside a pack carries the pack's licence — aggregators in
particular mix CC0 and CC-BY in one listing.

For each imported asset, `art/manifest.json` carries:

| field | what |
|---|---|
| `license` | the SPDX-ish identifier as published (`CC0`, `CC-BY-4.0`) |
| `source_url` | the page the model was downloaded from, not the CDN link |
| `author` | the credited creator |
| `source` | the import recipe that reproduces the fixed-up file |

## Sources in use

Licence read from `License.txt` inside each downloaded archive, not from the
website: *"License: (Creative Commons Zero, CC0)"* — Space Kit 2.0 and Blocky
Characters 2.0, both Kenney.

Two packs, and the second one contributes no geometry at all. The Space Kit
astronaut is the right look and ships no animation; Blocky Characters ship 27
clips on six boxes that would be a downgrade to look at. So the characters
below are Space Kit geometry carrying Blocky Characters **clips**, retargeted

## Candidate packs

Checked for style fit (low-poly, flat-shaded, bold colour — `docs/GDD.md`
pillar 4), not yet for per-model licence:

- **Kenney** — kenney.nl. Space Kit, Blaster Kit, Prototype/Mini Characters,
  Nature Kit. Published CC0. Colour usually lives in a texture atlas rather
  than in `baseColorFactor`, which `import_pack.mjs` cannot bake — those models
  need their palette re-applied per material before import.
- **Quaternius** — quaternius.com. Ultimate Space Kit, Sci-Fi Guns, Ultimate
  Modular Sci-Fi Characters, Universal Animation Library, Ultimate Rocks.
  Published CC0, generally flat per-material colour, which bakes cleanly.
- **Poly Pizza** — an aggregator. Mixed CC0 and CC-BY. Check every model
  individually; a CC-BY model obliges a credit line in the shipped game, not
  only in this file.

## Reproducing an import

The downloaded packs live in `art/vendor/`, which is gitignored — they are
re-downloadable from `source_url` and do not belong in the repo. What git
tracks is the fixed-up `.glb` the game ships, plus the recipe that produced it:

```sh
cd art
node tools/import_pack.mjs recipes/npc.grunt.json
npm run verify
```
